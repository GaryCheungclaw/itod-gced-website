# Itod GCED — Indifferent to Difference

AISG 社团官网（静态站，纯 HTML/CSS/JS）。

## 结构
- `index.html` — 首页（社团介绍 + 活动时间轴）
- `about.html` — 关于我们
- `activities.html` — 活动
- `awareness.html` — 科普
- `data/events.json` — 活动数据唯一真源（改这里全站生效）
- `css/style.css` / `js/main.js` — 样式与交互
- `img/` — 图片素材（logo、往届活动照、合作方 logo）

## 更新方式
改完文件后 `git add -A && git commit -m "..." && git push`，GitHub Pages 自动更新。
